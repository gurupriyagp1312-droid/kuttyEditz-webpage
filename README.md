🖼️ Kutty Editz Frame Shop

«A modern, responsive, and user-friendly Photo Frame Shop website built using HTML, CSS, and JavaScript. ✨»

---

🌟 Project Overview

Kutty Editz Frame Shop is a premium photo frame showcase website designed to provide customers with an easy and attractive way to explore different frame sizes and prices.

The website features a clean layout, responsive design, instant search functionality, and quick WhatsApp ordering to make shopping simple and convenient.

---

✨ Features

- 🏠 Modern Home Page
- 🎨 Beautiful Hero Banner
- 🖼️ Premium Photo Frame Gallery
- 💰 Complete Frame Price List
- 🔍 Live Search Functionality
- 📱 Fully Responsive Design
- 💬 One-Click WhatsApp Ordering
- 📞 Click-to-Call Support
- 📍 Contact Information Section
- ⚡ Smooth Hover Animations
- 🎯 Clean & Professional UI
